# league_drawer


## Things To Know
 
* do NOT alter or change ANY line of text in the files with the following format:
 - .py
 - .md
 - .hex

* to play / use the code, simply compile the *main.py* file with the terminal, or simply execute after opening the file
* the following steps to compile with the terminal
	1. open the Command Prompt on Windows or the Terminal on Mac
	2. make sure to have python3 installed on the latest version
		- to test it, type this in the terminal:
	`python3` or `python` depending on what you downloaded
	=> it should give you information about python software that was downloaded
	3. type in:
	`cd The/Installed/File/Path/Of/league_drawer`
	4. after selecting the whole folder for the software, execute by typing:
	`python3 main.py` or `python main.py`
	5. enjoy using the program!
